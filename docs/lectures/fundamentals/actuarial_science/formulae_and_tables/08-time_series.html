8.1 Time-domain identities

Sample autocovariance, autocorrelation
$$\hat{\gamma}_k = \frac{1}{n} \sum_{t = k+1}^{n} (x_t - \hat{\mu})(x_{t-k} - \hat{\mu}), \qquad \hat{\mu} = \frac{1}{n} \sum_{t=1}^{n} x_t$$ $$\hat{\rho}_k = \frac{\hat{\gamma}_k}{\hat{\gamma}_0}$$
ACF of ARMA(1, 1)
For $X_t = \alpha X_{t-1} + e_t + \beta e_{t-1}$, $$\rho_k = \frac{(1 + \alpha \beta)(\alpha + \beta)}{1 + \beta^2 + 2 \alpha \beta} \cdot \alpha^{k-1}, \quad k = 1, 2, \ldots$$
PACF (general)
$\phi_1 = \rho_1$ and for $k \geq 2$, $$\phi_k = \frac{\det P^*_k}{\det P_k},$$ where $P_k$ is the $k \times k$ Toeplitz autocorrelation matrix and $P^*_k$ is $P_k$ with the last column replaced by $(\rho_1, \rho_2, \ldots, \rho_k)^{\top}$. Explicit: $\phi_2 = (\rho_2 - \rho_1^2)/(1 - \rho_1^2)$.
PACF of MA(1)
For $X_t = \mu + e_t + \beta e_{t-1}$, $$\phi_k = (-1)^{k + 1} \frac{(1 - \beta^2) \beta^k}{1 - \beta^{2(k+1)}}, \quad k = 1, 2, \ldots$$

8.2 Box-Jenkins diagnostics

Ljung-Box portmanteau test
For an ARMA($p, q$) fit with residual autocorrelations $r_1, \ldots, r_m$, $$Q = n(n + 2) \sum_{k=1}^{m} \frac{r_k^2}{n - k} \sim \chi^2_{m - (p + q)}\text{ approximately under } H_0.$$ $H_0$ is that the residuals are white noise.
Turning-point test
For $n$ independent random variables, the number of turning points $T$ has $$E(T) = \tfrac{2}{3}(n - 2), \qquad \text{var}(T) = \frac{16 n - 29}{90}.$$ Used as a quick check for serial structure in residuals.
