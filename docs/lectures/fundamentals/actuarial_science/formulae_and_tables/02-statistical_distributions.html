Statistical distributions

Probability and density functions, generating functions, and the first two moments for the distributions every actuarial syllabus assumes.

Section 2 of 10 Source: Curtin §2, IFoA orange book §2

2.0 Notation

Generating functions
PF $p(x) = P(X = x)$; PDF $f(x) = \tfrac{d}{dx} F(x)$; DF $F(x) = P(X \leq x)$; PGF $G(s) = E(s^X)$; MGF $M(t) = E(e^{tX})$.
Moments from the MGF
If $M(t)$ is $r$ times differentiable at $0$, $M^{(r)}_X(0) = E(X^r)$.
Cumulant generating function
$C(t) = \log M(t)$. Then $C'(0) = E(X)$, $C''(0) = \text{var}(X)$, $C'''(0) = E\!\left[(X - E(X))^3\right]$.

2.1 Discrete distributions

Binomial $(n, p)$

PF
$p(x) = \binom{n}{x} p^x q^{n-x}$, $x = 0, 1, \ldots, n$, with $q = 1 - p$.
PGF, MGF
$G(s) = (q + ps)^n$, $M(t) = (q + p e^t)^n$.
Moments
$E(X) = np$, $\text{var}(X) = npq$, skewness $\dfrac{q - p}{\sqrt{npq}}$.

The Bernoulli distribution is the special case $n = 1$.

Poisson $(\mu)$

PF
$p(x) = \dfrac{e^{-\mu} \mu^x}{x!}$, $x = 0, 1, 2, \ldots$
PGF, MGF
$G(s) = e^{\mu(s-1)}$, $M(t) = e^{\mu(e^t - 1)}$.
Moments
$E(X) = \mu$, $\text{var}(X) = \mu$, skewness $1/\sqrt{\mu}$.

Negative binomial Type 1 $(k, p)$

PF
$p(x) = \binom{x-1}{k-1} p^k q^{x-k}$, $x = k, k+1, \ldots$ Counts trials until the $k$th success.
PGF, MGF
$G(s) = \left(\dfrac{ps}{1 - qs}\right)^k$, $M(t) = \left(\dfrac{p e^t}{1 - q e^t}\right)^k$.
Moments
$E(X) = k/p$, $\text{var}(X) = kq/p^2$, skewness $\dfrac{2 - p}{\sqrt{kq}}$.

Negative binomial Type 2 $(k, p)$

PF
$p(x) = \dfrac{\Gamma(k+x)}{\Gamma(x+1)\Gamma(k)} p^k q^x$, $x = 0, 1, 2, \ldots$ Counts failures before the $k$th success.

The geometric distribution is the Type 1 negative binomial with $k = 1$.

Uniform (discrete) $(a, b, h)$

PF
$p(x) = \dfrac{h}{b - a + h}$, $x = a, a+h, \ldots, b$.
Moments
$E(X) = \tfrac{1}{2}(a + b)$, $\text{var}(X) = \tfrac{1}{12}(b - a)(b - a + 2h)$.

2.2 Continuous distributions

Standard normal $N(0, 1)$

PDF, MGF
$f(x) = \dfrac{1}{\sqrt{2\pi}} e^{-x^2/2}$, $M(t) = e^{t^2/2}$.
Even moments
$E(X^r) = \dfrac{1}{2^{r/2}} \dfrac{\Gamma(1 + r)}{\Gamma(1 + r/2)}$ for $r = 2, 4, 6, \ldots$

Normal $N(\mu, \sigma^2)$

PDF
$f(x) = \dfrac{1}{\sigma \sqrt{2\pi}} \exp\!\left\{-\tfrac{1}{2}\!\left(\dfrac{x - \mu}{\sigma}\right)^{\!2}\right\}$
MGF, moments
$M(t) = \exp\!\left(\mu t + \tfrac{1}{2}\sigma^2 t^2\right)$; $E(X) = \mu$, $\text{var}(X) = \sigma^2$.

Exponential $(\lambda)$

PDF, DF
$f(x) = \lambda e^{-\lambda x}$, $F(x) = 1 - e^{-\lambda x}$, $x > 0$.
MGF, moments
$M(t) = (1 - t/\lambda)^{-1}$ for $t < \lambda$. $E(X) = 1/\lambda$, $\text{var}(X) = 1/\lambda^2$, skewness $= 2$. $E(X^r) = \Gamma(1+r)/\lambda^r$.

Gamma $(\alpha, \lambda)$

PDF
$f(x) = \dfrac{\lambda^{\alpha}}{\Gamma(\alpha)} x^{\alpha - 1} e^{-\lambda x}$, $x > 0$.
MGF
$M(t) = (1 - t/\lambda)^{-\alpha}$ for $t < \lambda$.
Moments
$E(X) = \alpha/\lambda$, $\text{var}(X) = \alpha/\lambda^2$, skewness $2/\sqrt{\alpha}$. $E(X^r) = \dfrac{\Gamma(\alpha + r)}{\Gamma(\alpha) \lambda^r}$.
Chi-square link
If $2\alpha$ is an integer, $2 \lambda X \sim \chi^2_{2\alpha}$. The $\chi^2_{\nu}$ distribution is gamma with $\alpha = \nu/2$, $\lambda = 1/2$.

Uniform (continuous) $U(a, b)$

PDF, DF
$f(x) = \dfrac{1}{b - a}$, $F(x) = \dfrac{x - a}{b - a}$ for $a < x < b$.
Moments
$E(X) = \tfrac{1}{2}(a+b)$, $\text{var}(X) = \tfrac{1}{12}(b-a)^2$. $E(X^r) = \dfrac{b^{r+1} - a^{r+1}}{(b-a)(r+1)}$.

Beta $(\alpha, \beta)$

PDF
$f(x) = \dfrac{\Gamma(\alpha + \beta)}{\Gamma(\alpha) \Gamma(\beta)} x^{\alpha - 1} (1 - x)^{\beta - 1}$, $0 < x < 1$.
Moments
$E(X) = \dfrac{\alpha}{\alpha + \beta}$, $\text{var}(X) = \dfrac{\alpha \beta}{(\alpha + \beta)^2 (\alpha + \beta + 1)}$.

Lognormal $(\mu, \sigma^2)$

PDF
$f(x) = \dfrac{1}{x \sigma \sqrt{2\pi}} \exp\!\left\{-\tfrac{1}{2}\!\left(\dfrac{\log x - \mu}{\sigma}\right)^{\!2}\right\}$, $x > 0$.
Moments
$E(X^r) = \exp(r \mu + \tfrac{1}{2} r^2 \sigma^2)$. Hence $E(X) = e^{\mu + \sigma^2/2}$, $\text{var}(X) = [E(X)]^2 (e^{\sigma^2} - 1)$.

Pareto (two-parameter, $\alpha, \lambda$)

PDF, DF
$f(x) = \dfrac{\alpha \lambda^{\alpha}}{(\lambda + x)^{\alpha + 1}}$, $F(x) = 1 - \left(\dfrac{\lambda}{\lambda + x}\right)^{\alpha}$, $x > 0$.
Moments (where finite)
$E(X) = \dfrac{\lambda}{\alpha - 1}$ ($\alpha > 1$), $\text{var}(X) = \dfrac{\alpha \lambda^2}{(\alpha - 1)^2 (\alpha - 2)}$ ($\alpha > 2$). $E(X^r) = \dfrac{\Gamma(\alpha - r) \Gamma(1 + r)}{\Gamma(\alpha)} \lambda^r$ for $r < \alpha$.

Three-parameter (generalised) Pareto $(\alpha, \lambda, k)$: $f(x) = \dfrac{\Gamma(\alpha + k) \lambda^{\alpha} x^{k - 1}}{\Gamma(\alpha) \Gamma(k) (\lambda + x)^{\alpha + k}}$, $x > 0$.

Weibull $(c, \gamma)$

PDF, DF
$f(x) = c \gamma x^{\gamma - 1} e^{-c x^{\gamma}}$, $F(x) = 1 - e^{-c x^{\gamma}}$, $x > 0$.
Moments
$E(X^r) = \dfrac{\Gamma(1 + r/\gamma)}{c^{r/\gamma}}$.

Burr $(\alpha, \lambda, \gamma)$

PDF, DF
$f(x) = \dfrac{\alpha \gamma \lambda^{\alpha} x^{\gamma - 1}}{(\lambda + x^{\gamma})^{\alpha + 1}}$, $F(x) = 1 - \left(\dfrac{\lambda}{\lambda + x^{\gamma}}\right)^{\alpha}$, $x > 0$.
Moments
$E(X^r) = \dfrac{\Gamma(\alpha - r/\gamma) \Gamma(1 + r/\gamma) \lambda^{r/\gamma}}{\Gamma(\alpha)}$ for $r < \alpha \gamma$.

2.3 Compound distributions

Tower property

Conditional moments
$E(Y) = E[E(Y \mid X)]$ and $\text{var}(Y) = \text{var}[E(Y \mid X)] + E[\text{var}(Y \mid X)]$.

Compound sum $S = X_1 + \cdots + X_N$

Mean, variance
$E(S) = E(N) E(X)$; $\text{var}(S) = E(N) \text{var}(X) + \text{var}(N) [E(X)]^2$.
MGF
$M_S(t) = M_N\!\big(\log M_X(t)\big)$.

Compound Poisson

Cumulants
If $N \sim \text{Poisson}(\lambda)$ and $m_r = E(X^r)$, the first three central moments of $S$ are $\lambda m_1$, $\lambda m_2$, $\lambda m_3$ respectively.

2.4 Truncated moments

Let $\phi(z)$ and $\Phi(z)$ denote the PDF and DF of $Z \sim N(0,1)$.

Normal $\int_L^U x f(x) dx$
For $f$ the PDF of $N(\mu, \sigma^2)$, $$\int_L^U x f(x)\,dx = \mu \big[\Phi(U') - \Phi(L')\big] - \sigma \big[\phi(U') - \phi(L')\big],$$ where $L' = (L - \mu)/\sigma$ and $U' = (U - \mu)/\sigma$.
Lognormal $\int_L^U x^k f(x) dx$
For $f$ the lognormal PDF, $$\int_L^U x^k f(x)\,dx = e^{k \mu + \tfrac{1}{2} k^2 \sigma^2} \big[\Phi(U_k) - \Phi(L_k)\big],$$ where $L_k = \dfrac{\log L - \mu}{\sigma} - k \sigma$ and $U_k = \dfrac{\log U - \mu}{\sigma} - k \sigma$.
