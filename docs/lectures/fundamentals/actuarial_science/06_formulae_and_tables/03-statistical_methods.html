Statistical methods

Sample moments, maximum likelihood, linear regression, generalised linear models, Bayesian methods, and empirical Bayes credibility.

3.1 Sample mean and variance

Sample moments
For a random sample $x_1, \ldots, x_n$, $$\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i, \qquad s^2 = \frac{1}{n - 1}\!\left(\sum_{i=1}^{n} x_i^2 - n \bar{x}^2\right).$$

3.2 Maximum likelihood

Asymptotic distribution
The MLE $\hat{\theta}$ is asymptotically $N\!\left(\theta, \text{CRLB}(\theta)\right)$, where the Cramér-Rao lower bound is $$\text{CRLB}(\theta) = -\,1 \big/ E\!\left[\frac{\partial^2}{\partial \theta^2} \log L(\theta; X)\right].$$
Likelihood ratio test
Under $H_0$, $$-2 (\ell_p - \ell_{p+q}) = -2 \log\!\left(\frac{\max_{H_0} L}{\max_{H_0 \cup H_1} L}\right) \sim \chi^2_q \text{ approximately},$$ where the unrestricted model has $p + q$ free parameters and the restricted has $p$.

3.3 Linear regression with normal errors

Model
$Y_i \sim N(\alpha + \beta x_i, \sigma^2)$, $i = 1, \ldots, n$.
Sums of squares
$$s_{xx} = \sum (x_i - \bar{x})^2 = \sum x_i^2 - n \bar{x}^2$$ $$s_{yy} = \sum (y_i - \bar{y})^2 = \sum y_i^2 - n \bar{y}^2$$ $$s_{xy} = \sum (x_i - \bar{x})(y_i - \bar{y}) = \sum x_i y_i - n \bar{x} \bar{y}$$
Parameter estimates
$$\hat{\beta} = \frac{s_{xy}}{s_{xx}}, \qquad \hat{\alpha} = \bar{y} - \hat{\beta} \bar{x}$$ $$\hat{\sigma}^2 = \frac{1}{n - 2}\!\left(s_{yy} - \frac{s_{xy}^2}{s_{xx}}\right)$$

3.4 Generalised linear models

Exponential family
$$f_Y(y; \theta, \phi) = \exp\!\left[\frac{y \theta - b(\theta)}{a(\phi)} + c(y, \phi)\right]$$ with $E(Y) = b'(\theta)$ and $\text{var}(Y) = a(\phi) b''(\theta)$.
Canonical link functions
Binomial: $g(\mu) = \log\!\dfrac{\mu}{1 - \mu}$. Poisson: $g(\mu) = \log \mu$. Normal: $g(\mu) = \mu$. Gamma: $g(\mu) = 1/\mu$.

3.5 Bayesian methods

Posterior
$f(\theta \mid x) \propto f(\theta) \times f(x \mid \theta)$; that is, posterior $\propto$ prior $\times$ likelihood.
Normal-normal model
If $x$ is a random sample of size $n$ from $N(\mu, \sigma^2)$ with $\sigma^2$ known, and the prior on $\mu$ is $N(\mu_0, \sigma_0^2)$, then the posterior is $\mu \mid x \sim N(\mu_*, \sigma_*^2)$ where $$\mu_* = \frac{n \bar{x}/\sigma^2 + \mu_0/\sigma_0^2}{n/\sigma^2 + 1/\sigma_0^2}, \qquad \sigma_*^2 = \frac{1}{n/\sigma^2 + 1/\sigma_0^2}.$$

3.6 Empirical Bayes credibility — Model 1

Data
$\{X_{ij}\}$ where $i = 1, \ldots, N$ indexes risks and $j = 1, \ldots, n$ indexes years. $X_{ij}$ is aggregate claims in year $j$ from risk $i$.
Means
$\bar{X}_i = \dfrac{1}{n} \sum_j X_{ij}$, $\bar{\bar{X}} = \dfrac{1}{N} \sum_i \bar{X}_i$.
Parameter estimators
$E[m(\theta)]: \bar{\bar{X}}$
$E[s^2(\theta)]: \dfrac{1}{N} \sum_i \dfrac{1}{n - 1} \sum_j (X_{ij} - \bar{X}_i)^2$
$\text{var}[m(\theta)]: \dfrac{1}{N - 1} \sum_i (\bar{X}_i - \bar{\bar{X}})^2 - \dfrac{1}{Nn} \sum_i \dfrac{1}{n - 1} \sum_j (X_{ij} - \bar{X}_i)^2$
Credibility factor
$$Z = \frac{n}{n + \dfrac{E[s^2(\theta)]}{\text{var}[m(\theta)]}}$$
Credibility premium
$Z \bar{X}_k + (1 - Z) \bar{\bar{X}}$ for risk $k$. The direct estimate is weighted with the collateral mean by the credibility factor.

3.7 Empirical Bayes credibility — Model 2

Data
$\{Y_{ij}, P_{ij}\}$. $Y_{ij}$ is aggregate claims in year $j$ from risk $i$; $P_{ij}$ is the corresponding risk volume (exposure).
Intermediate quantities
$P_i = \sum_j P_{ij}$, $P = \sum_i P_i$, $P^* = \dfrac{1}{Nn - 1} \sum_i P_i \!\left(1 - \dfrac{P_i}{P}\right)$.
$X_{ij} = Y_{ij}/P_{ij}$, $\bar{X}_i = \sum_j P_{ij} X_{ij} / P_i$, $\bar{\bar{X}} = \sum_i \sum_j P_{ij} X_{ij} / P$.
Parameter estimators
$E[m(\theta)]: \bar{\bar{X}}$
$E[s^2(\theta)]: \dfrac{1}{N} \sum_i \dfrac{1}{n - 1} \sum_j P_{ij} (X_{ij} - \bar{X}_i)^2$
$\text{var}[m(\theta)]: \dfrac{1}{P^*}\!\left[\dfrac{1}{Nn - 1} \sum_{i,j} P_{ij} (X_{ij} - \bar{\bar{X}})^2 - \dfrac{1}{N} \sum_i \dfrac{1}{n - 1} \sum_j P_{ij} (X_{ij} - \bar{X}_i)^2\right]$
Credibility factor
$$Z_i = \frac{P_i}{P_i + \dfrac{E[s^2(\theta)]}{\text{var}[m(\theta)]}}$$
