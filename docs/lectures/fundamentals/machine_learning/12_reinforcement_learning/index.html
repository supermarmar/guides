Reinforcement learning

The twelfth and final sub-module of the machine learning course, and the one genuine departure from everything before it. Every model built so far, supervised, unsupervised, or generative, predicts something about a process it does not itself influence. Reinforcement learning studies an agent that takes actions which change the very process being modelled, and learns from rewards rather than correct answers. Seven lectures move from the conceptual break with forecasting, through the explore-exploit trade-off in its simplest form (bandits), through incremental and temporal-difference learning, the full Markov decision process framework, dynamic programming when the environment's dynamics are known, Monte Carlo and temporal-difference control when they are not, and close with the deep reinforcement learning architectures (DQN, policy gradients, actor-critic, PPO) that power the RLHF pipeline behind every modern large language model.

How to use this

Read in strict order; this sub-module builds a single cumulative framework more tightly than any other in this course. Lecture 1 is the conceptual foundation everything else depends on. Lectures 2 and 3 build the two ideas (exploration versus exploitation, incremental updating) inside the simplest possible setting, a single state, before lecture 4 generalises to the full multi-state Markov decision process. Lectures 5 and 6 are the two branches of solving an MDP, known dynamics versus unknown dynamics, and lecture 7 scales the unknown-dynamics branch up with deep function approximation. A note on terminology: the reinforcement-learning literature uses several words (value, policy, return, advantage) in ways that overlap with but are not identical to their use elsewhere in this course; each lecture flags the divergence where it matters. Status badges show what is built (built) or planned.
