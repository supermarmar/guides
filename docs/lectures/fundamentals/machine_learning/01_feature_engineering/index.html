Feature engineering

The first sub-module of the machine learning course, and the first stage of the ML pipeline. Four lectures: a course-wide framing of where ML sits and how it is shaped, followed by the three pillars of feature engineering itself — transforming features so algorithms can use them, reducing dimensionality so the geometry stays tractable, and selecting features so noise is left on the cutting-room floor. Every later sub-module assumes the features are model-ready in the sense built here.

How to use this

Each lecture rebuilds one part of the underlying wiki notes as a teaching session: intuition first, every formula derived in full, a worked example near the end. The lectures are sequenced so each depends on the previous: the landscape lecture sets the vocabulary for everything that follows, transformation puts the raw features into shape, dimensionality reduction compresses the geometry, and selection prunes what is left. Status badges show what is built (built) or planned.
