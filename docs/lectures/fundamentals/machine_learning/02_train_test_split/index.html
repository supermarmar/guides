Train and test split

The second sub-module of the machine learning course, and the second stage of the ML pipeline. Two lectures: how to partition the data so the model is fit on one subset, tuned on a second, and evaluated honestly on a third, and how to encode the whole feature-and-model workflow as a single pipeline object so leakage is impossible by construction. This sub-module is the smallest in the course and the one whose details most often decide whether a project succeeds or quietly fails.

How to use this

Both lectures assume the feature engineering sub-module's framing: features have been prepared, and the question is now how to slice the data for fitting and assessment. Lecture 1 covers the partitioning strategies (basic split, stratified, k-fold cross-validation, time-series cross-validation, group-aware splits) plus the population stability index used at deployment. Lecture 2 turns the whole workflow into a scikit-learn pipeline, which is the only construction that makes the leakage rule from the previous sub-module automatic. Status badges show what is built (built) or planned.
