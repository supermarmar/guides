Unsupervised learning

The fourth sub-module of the machine learning course. Seven lectures answer the question every modeller asks at some point, there are no labels, but is there structure, from four genuinely different angles: partitional clustering (k-means, K-medoids), linear and non-linear dimensionality reduction (PCA, autoencoders), hierarchical and density-based clustering (DIANA/AGNES, DBSCAN), probabilistic clustering (Gaussian mixtures via EM), and, closing the sub-module, the non-linear embeddings (t-SNE, UMAP) most practitioners reach for first when exploring high-dimensional data.

How to use this

Read in order: lectures 1 to 3 build the two dissimilarity-based foundations (centroid clustering, linear and non-linear dimensionality reduction), lectures 4 to 6 develop three further, genuinely distinct clustering families (hierarchical, medoid and mixture-based, density-based), and lecture 7 closes with the non-linear embeddings used to visualise all of it. PCA appeared briefly in the dimensionality reduction lecture in sub-module 01; this sub-module gives PCA its full mathematical treatment (covariance matrix, eigendecomposition, the Lagrangian derivation of the variance-maximisation objective) before lecture 3 generalises it via the autoencoder framework.
