Hyperparameter tuning

The sixth sub-module of the machine learning course and the fourth stage of the pipeline. Every model has knobs that are not fit by the data (number of trees, depth of a network, regularisation strength, learning rate); five lectures cover the four canonical ways to choose them. Two are first principles: tuning principles framed against the bias-variance axis, and the validation strategy that makes the search honest. Three are algorithms: grid, random, and Bayesian search. Two further lectures fill wiki stubs: Bayesian optimisation given its own deep treatment, and genetic algorithms as a complementary global search method.

How to use this

Start with the tuning principles lecture; it sets up the validation strategy and the bias-variance reading every later lecture in this sub-module relies on. Then read the three search algorithms in order: grid (the brute-force baseline), random (often better in practice for high-dimensional spaces), Bayesian (the model-based approach when each evaluation is expensive). Genetic algorithms close the set as a complementary global-search method. Status badges show what is built (built), planned, or expanded from a wiki stub gap-fill.
