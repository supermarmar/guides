Model evaluation

The seventh sub-module of the machine learning course and the fifth stage of the pipeline. Four lectures cover the metrics and diagnostics that turn a fitted model into a defensible one. Relative model performance via information criteria, regression diagnostics via residual analysis, classification metrics with the credit-risk reading of AUC and Gini, and forecasting evaluation including the autocorrelation tests and backtests every IRRBB and time-series model is judged against. The bias-variance trade-off introduced in lecture 1 makes its final appearance here.

How to use this

The four lectures correspond to four different model output types. Read whichever matches the model you are evaluating; you can read them in any order, but the suggested sequence below is conceptual rather than dependent: information criteria first (the relative question), then regression diagnostics, then classification, then forecasting. The forecasting lecture closes with a recap of the bias-variance trade-off as it appears across the whole course. Status badges show what is built (built) or planned.
