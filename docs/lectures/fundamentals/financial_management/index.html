Course companion

Financial management

An intro to financial management theory, built from the University of Pretoria course and extended with the classic results, recent data, and the depth you would expect from a graduate textbook. Nine lectures, sequenced foundation first.

How to use this

Each lecture takes one source PDF and rebuilds it as a teaching session, with intuition first, visuals throughout, and depth where the source was thin. Lectures are sequenced so that each one builds on the previous. Status badges show what is built (built) or planned.
