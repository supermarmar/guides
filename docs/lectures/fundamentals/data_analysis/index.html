Course companion

Data analysis

An eleven-lecture course on the dataframe layer of analytical Python and the design discipline that sits on top of it, written for the working credit risk analyst. Pandas for the canonical vocabulary, Polars for the modern engine, exploratory data analysis as a verdict-producing discipline, and visualisation as honest compression, closing with a dedicated six-lecture sub-module on visualisation design: the history, perceptual science, colour, audience, structure, and figure conventions underneath any single plotting call. Examples use a 32,000-row credit risk dataset throughout, so the techniques land on the kind of work the audience does. Sits beneath the statistics and machine-learning tracks: every model in those courses starts with a typed dataframe, a quality verdict, and a picture.

The data analysis pipeline

Every analytical workflow is a pipeline of the same four stages: load a rectangle into memory, fold and combine rectangles into the shape the question wants, describe what is in the rectangle, and visualise the description. The five lectures below cover the four stages, with Polars treated as a parallel engine for the load-and-fold half.

How to use this

Lectures are sequenced as prerequisites of the next. Part I (lectures 01-03) builds the dataframe layer: pandas for the canonical vocabulary, Polars for the engine that scales an order of magnitude beyond pandas. Part II (lectures 04-05) is the descriptive and communication discipline that sits on top. Part III (lectures 06-11, the visualisation design sub-module) is the reasoning underneath lecture 05's practical plotting calls: history, perception, colour, audience, structure, and figure conventions. Status badges show what is built (built) or planned. Lectures 01-05 use a credit-risk loan dataset throughout, so techniques land on the kind of work the audience does.

Prerequisites and adjacent courses

The course assumes basic Python (covered in the software engineering track) and no prior pandas. The natural next courses are statistics (to turn descriptive verdicts into inferential ones), machine learning (to turn descriptive features into predictive models), and the data engineering wiki (for the SQL and DuckDB context that produces the dataframes this course consumes). The credit-risk modelling track in application/banking uses every technique here in its data engineering, EDA, feature engineering, and monitoring stages.
