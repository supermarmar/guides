Life insurance is sequenced at 64 lectures with 10 written, including the complete products module. Inside fundamentals, the 68-lecture writing course is complete across all nine modules, a 28-lecture design course is complete, with eight machine-readable token specifications alongside it, and a 22-lecture Claude engineering course is complete.

How to use this

Lectures are sequenced bottom up. Each lecture is self-contained, but the chain rewards order. Status badges show what is built (built), planned, or a gap (source note is a stub, so the lecture goes beyond the wiki). Each course folder carries its own landing page with the authoritative lecture list for that course; this page is the map, not the detail.

Both the internal and external environments are complete, including all six indices lectures. The asset class framework is the entry point and every later asset class lecture applies it. Phase 1c: life insurance applications (F102)

Sixty-four lectures sequenced, none built. The track keeps the banking and investments two-folder shape, but below that it diverges: risk measurement is organised by what the actuary produces (an asset share, a bonus declaration, a reserve, a capital requirement, a surrender value, an analysis of surplus) rather than by risk type, because F102 has no risk-type taxonomy to mirror. All thirty-six syllabus chapters are covered. The sequence is weighted by where marks are lost rather than by chapter count, so with-profits distribution and policyholder values take eleven lectures between them for four chapters.
